# Медиапортал

Учебный REST API для статей, видео и подкастов. Java 21, Spring Boot, PostgreSQL 17, Flyway.

## Запуск

Нужны Docker и Docker Compose v2. Из корня проекта:

```bash
docker compose up --build -d
```

Первый запуск занимает несколько минут: скачиваются зависимости и образы.
Приложение: `http://localhost:8080/api/articles`.
Swagger UI: `http://localhost:8080/swagger-ui/index.html`.
OpenAPI JSON: `http://localhost:8080/v3/api-docs` (копия схемы — `docs/openapi.json`).
Если приложение ещё запускается, проверьте `docker compose logs -f app`.
Порты 8080 и 5432 должны быть свободны.

Остановка: `docker compose down`. Данные сохраняются в томе.
Для полного удаления данных: `docker compose down -v`.
Логин и пароль БД `media` используются только для локального учебного запуска.

## API

Для каждого пути `/api/articles`, `/api/videos`, `/api/podcasts`:

| Метод | Путь | Результат |
| --- | --- | --- |
| POST | базовый путь | Создание, 201 и Location |
| GET | базовый путь | Список, 200 |
| GET | базовый путь/{id} | Один объект, 200 |
| PUT | базовый путь/{id} | Полная замена, 200 |
| DELETE | базовый путь/{id} | Удаление, 204 |

Нет объекта — 404, неверные данные — 400. Ошибки имеют поля `timestamp`, `status`, `message`, `errors`.
Поля контента обязательны. Длительность — целое число секунд больше нуля, номер эпизода — положительный и уникальный в подкасте. URL должны начинаться с HTTP или HTTPS. Дата статьи — `YYYY-MM-DD`.
Эпизоды создаются и обновляются вместе с подкастом; PUT заменяет весь список. Пустой список разрешён. При удалении подкаста удаляются его эпизоды.

## Демонстрация

1. Откройте Swagger UI или импортируйте `postman/MediaPortal.postman_collection.json` в Postman.
2. В Postman выполните пять запросов каждой папки по порядку. После POST идентификатор сохраняется автоматически. Коллекция проверяет HTTP-статусы.
3. Пример создания статьи:

```bash
curl -i -X POST http://localhost:8080/api/articles \
  -H 'Content-Type: application/json' \
  -d '{"title":"Первая статья","text":"Текст статьи","author":"Иван","publicationDate":"2026-01-01"}'
```

4. Используйте полученный `id` для GET, PUT и DELETE. После удаления GET вернёт 404.
5. Отправьте пустой заголовок — получите 400 с ошибкой поля `title`. Для подкаста попробуйте добавить два эпизода с одинаковым номером — запрос тоже будет отклонён.

## Разработка и тесты

Нужны JDK 21, Maven 3.9+ и работающий Docker 25+ (API 1.44). Тесты выполняются командой:

```bash
mvn test
```

Модульные тесты проверяют сервисы через Mockito. Интеграционные тесты запускают отдельный PostgreSQL через Testcontainers: проверяют миграции на пустой базе, CRUD, ошибки, замену и удаление эпизодов, Swagger. Рабочую базу приложения они не затрагивают.

Сборка: `mvn clean package` (включает тесты).
Для запуска без контейнера приложения сначала выполните `docker compose up -d db`, затем `mvn spring-boot:run`.
Подключение переопределяется переменными `DB_URL`, `DB_USER`, `DB_PASSWORD`.

Код разделён на controller, service, repository, entity и dto.
Структуру БД создаёт только Flyway, Hibernate проверяет её через `ddl-auto: validate`.
Дополнительное задание с MongoDB/Redis не выполнялось.
